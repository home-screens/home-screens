## New

- IP allowlist — restrict access to specific devices on your network using CIDR ranges, or let trusted IPs skip the login password entirely. Lockout protection warns you before saving a rule that would block your own device, and the login page shows a clear message when access is restricted by IP
- Rewards store view for the fullscreen chore chart — kids browse available rewards, see their ticket balance, and redeem directly from the display. Rewards can be age-gated to specific family members
- Chore schedule rotation — assign chores to specific family members on specific days of the week, with a visual schedule grid in both the editor and remote control
- Chore history backdating — admins can mark past days as complete from the remote control so missed check-offs don't get lost. A 90-day history strip makes it easy to scroll back
- Weather-aware greetings and affirmations — these modules now respond to current weather conditions, showing contextual messages like "Rainy day ahead" beneath the greeting. Disable per-module if you prefer the original behavior
- Event bus for plugins — plugins can subscribe to live weather conditions, weather alerts, and time-of-day transitions so third-party modules can react to the same data built-in modules use
- Config validation CLI — run `npm run config:check` to scan your configuration for issues like unknown module types, broken profile references, or out-of-range settings
- Blog on homescreens.dev with RSS feed, changelog page with jump navigation, and a comparison page versus MagicMirror and Dakboard

## Improved

- Light, dark, and system theme support — the editor and remote control each remember their own theme preference, with semantic color tokens throughout for consistent styling
- "Points" renamed to "tickets" everywhere — editor, remote control, kid view, and display all use the friendlier term
- Weather settings redesigned as provider cards — each of the five providers gets its own card with status indicator, API key field, test button, and set-as-default action
- All API routes now automatically retry on server errors and rate limits with exponential backoff, so a momentary provider outage doesn't leave a blank widget
- 4X Large fullscreen typography size added for displays viewed from further away
- GitHub and homescreens.dev links in the editor settings sidebar
- Faster service restarts on Raspberry Pi — the systemd unit now caps shutdown to 15 seconds instead of the default 90

## Fixed

- Kid view (/chores) unable to toggle chores or redeem rewards when a password was set — the proxy's default-deny was blocking requests that should have been public
- Login page redirect loop when an authenticated admin's IP was later restricted — now shows a clear "access restricted" message instead of "too many redirects"
- Chore points rejecting a value of 0 — entering zero defaulted to 1 because of a falsy-check bug
- Snowstorm weather conditions misclassified as thunderstorms
- IP allowlist silently dropped when changing or clearing the password
- Weather-aware modules not working unless a weather widget was also on screen
- Malformed CIDR entries in a hand-edited config matching unintended IP ranges instead of being safely ignored
