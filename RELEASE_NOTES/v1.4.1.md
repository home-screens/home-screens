## Improved

- Calendar and Fullscreen Calendar modules can now show event descriptions under each event title — toggle per view (daily, agenda, schedule, week list, day timeline) in the editor; off by default so existing screens are unchanged. HTML and entities from ICS and Google feeds are converted to clean plain text.

## Fixed

- Installing a plugin from the marketplace no longer fails on fresh setups where no plugins have been added yet
- Color picker now accepts `rgba()`, `hsl()`, `hsla()`, named colors, and modern CSS color formats — pasted values with surrounding whitespace also save correctly
