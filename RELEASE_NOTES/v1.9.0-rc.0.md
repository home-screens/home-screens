## New

- Visual timers and routines: set quick timers (30 seconds to 15 minutes, or a custom length) and build multi-step routines from your phone, with an emoji and length for each step and "wait for a tap" holds. A running timer takes over the display full-screen with four looks to choose from (Glow ring, Timer face, Color fall, Star path), a nudge when time is almost up, optional soft chimes, and a celebration screen at the end. Pause, resume, skip, add a minute, or stop from the live control card; a running timer survives a restart, and routines are included in backups
- Google Photos import: bring photos from your Google Photos library into slideshows and fullscreen photo modules. Sign in with Google, pick the photos you want, and they download into your local photo library
- Swipe to change screens: flick left or right anywhere on a touchscreen display to go to the next or previous screen, with slide and flip transitions that mirror when you go backward. On by default with a per-display override, and a touch that wakes a sleeping display never also changes screens
- Voice control with Home Assistant: a new guide with a ready-to-paste setup so you can ask your voice assistant to check off chores, hear today's chore list, read out the grocery list, switch profiles, jump to a screen, or keep a display awake
- New remote commands for displays: send a display to a specific screen by name, and wake a display and hold it awake for a chosen number of minutes

## Improved

- Stock and crypto cards now show a small trend line (today's movement for stocks, the last 7 days for crypto), colored to match the change direction, with a toggle to turn it off
- New installs start with a weather provider that needs no API key, so weather works right after setup
- The chore chart now reads family members and chores from the shared family data everywhere, so displays, the remote, and the kids' page always agree
- Installing a plugin that isn't put together correctly now explains exactly what's wrong in plain language, and a failed plugin refresh keeps your current plugins running instead of removing them
- When saving a chore, reward, or meal change fails, the page now says so and puts things back the way they were instead of quietly losing the change
- Documentation refreshed to match current behavior, and the website changelog now keeps older releases on a separate archive page

## Fixed

- Homes with more than one display: the remote and the kids' chores page now find chore charts and meal planners on any display, not just the main one, and each display's status shows screen names from its own screen list
- Wake-up rules can now reliably wake a sleeping display and hold it awake so a sleep schedule doesn't put it right back to sleep moments later
- Plugin settings updates during an upgrade could be skipped entirely or applied inconsistently depending on which version you were coming from
- Installs and upgrades could fail on the Raspberry Pi because of a package tool bug; setup now accepts current versions of the tool instead of forcing one exact release
- Alerts set to stay on screen until dismissed now stay for every alert type, not just some
- A brief network hiccup no longer makes the editor forget which API keys you've saved, and the Todoist section no longer gets stuck on "Checking"
- Deleting a photo from the library now shows an error message when it fails instead of a stuck "Deleting" overlay
- Downloading layout and backup exports now works in Safari
- Dragging a brightness or volume slider on a touchscreen no longer flips to the next screen
- Deleting a display no longer briefly re-selects the display you just removed
- "all" can no longer be used as a display name, since it already means "every display" to remote commands
