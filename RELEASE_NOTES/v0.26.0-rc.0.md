## New

- Per-meal serving times — assign a specific time to individual meals and see it displayed as a time chip
- Shared meal planner settings — configure meal slots, week start day, default slot times, and time format from one place (editor Settings → Meals or the gear icon on the remote control page) and have it apply everywhere

## Improved

- Upgrade pipeline verifies release tarballs with SHA-256 checksums before installing
- Upgrade pipeline preserves rollback state if a restart fails and protects user data against power loss during upgrades
- Concurrent meal edits from the editor and remote control no longer overwrite each other thanks to atomic writes
- Plugin proxy hardened against DNS rebinding and redirect-based server-side request forgery

## Fixed

- Meal library could be silently wiped when saving under certain race conditions
- Active meal time slot on the remote control page froze at the time it was first opened instead of updating in real time
- Meal settings that fail to save now roll back and show an error instead of silently diverging from the server
- Changing Immich album, person, or favorites filters no longer requires a restart to refresh the photo slideshow
- Editing weather coordinates no longer triggers unnecessary API calls on every keystroke
- A transient config read error could silently reset the entire configuration to defaults
