## New

- Multi-display support — drive multiple screens from a single Home Screens hub. Assign each display its own set of screens, profiles, active profile, and settings overrides while keeping your existing single-display setup working unchanged
- New Displays settings tab in the editor with full create/edit/delete, online/offline status dots, and automatic adoption of new displays that connect to the hub
- Display picker in the remote control — target commands (brightness, profile switch, wake/sleep, next/prev) at a specific display or broadcast to all at once
- New installer flags (`--display-only`, `--backend`, `--display-id`) let you set up a secondary Pi as a display-only client that auto-connects to the hub, with an offline splash screen while it waits for the hub to come online

## Improved

- Screen selector now has select-all and clear-all buttons with an N/M counter, making it faster to assign screens to a display
- Deleting a screen or profile automatically cleans up any display references, so saves no longer fail after a deletion
- Profile switching on a per-display basis works alongside the existing global profile, so Home Assistant automations and bookmarks continue to work without changes
- Config saves are now atomic — the editor and display profile switches can no longer overwrite each other in a race condition

## Fixed

- Fullscreen meal planner showing "Now — Breakfast" late in the evening when no meal is active
- Upgrade path from v0.25.0 through v0.26.0 no longer fails due to missing cleanup scripts
