## New in this RC

- Multi-month calendar gains today markers (filled, square, outline, underline, colored number, or none) with a matching accent color, plus an option to hide the current month's heading so stacked months line up row for row.
- New Date Text Size slider on the calendar's week, month, and multi-week grids, so day names and numbers can be scaled up without changing the event text.
- The All Displays page now shows which screen each display is currently showing.
- Fix the history module coming up empty. The source was rate-limiting the app and the display could sit blank until the next day; it now retries properly and keeps the last known events on screen if a fetch fails.
- Fix calendar grids losing events on busy months and dropping earlier days when a view was set to show past events.

## New

- Rebuilt news module: follow several feeds at once with per-feed labels and colors, filter by age or keywords, and choose from 98 curated presets in every supported language. Also handles local news, topic searches, YouTube channels, and subreddits.
- New full-screen news module with story and front-page views in both portrait and landscape.
- OneDrive is now a photo source for the photo slideshow and full-screen photo modules. Sign in from settings, browse to a folder, and it pulls in photos from that folder and everything under it.
- Opt-in credential backup: backups can now include your API keys, calendar passwords, and connected accounts, optionally protected with a password you choose. Restoring without the password still restores everything else.
- Stock ticker tiles get a single-symbol mode that devotes the whole tile to one stock with a large price and a full-tile chart.
- Stock ticker tiles can now show a today chart, a past-week chart, or both side by side, with a new shaded theme.
- Show Title toggle on modules that draw their own heading (traffic, garbage day, history, news, todo, Todoist, weather, chore chart, and meal planner).
- Import a layout file straight from the + menu on the screen tabs, adding it as new screens on the display you are editing.
- Release notes now open in a full, readable dialog in System settings instead of a clipped preview, with a link to each release on GitHub.
- Multi-month calendar gains today markers (filled, square, outline, underline, colored number, or none) with a matching accent color, plus an option to hide the current month's heading so stacked months line up row for row.
- New Date Text Size slider on the calendar's week, month, and multi-week grids, so day names and numbers can be scaled up without changing the event text.

## Improved

- The display, remote, and chores pages now render in the app's own font instead of falling back to whatever the Raspberry Pi happened to pick, so text on the display matches what the editor previews.
- The Georgia font in the font picker now looks the same on the display as it does in the editor.
- Photo slideshows no longer jump to a different photo partway through a round, and turning shuffle off returns to the original order without restarting.
- Rain map tiles are kept cached across screens and modules, and the map now backs off politely when the tile service is busy, so frames stop appearing blank on startup.
- Removed the Max Events calendar setting, which was quietly trimming busy month grids down to a few days. Calendar health is now also shown per source in the editor preview.
- The Calendar settings page leads with What to show.
- Cross-origin writes to the app's API are now refused, so another site open in the same browser cannot change your configuration.
- The All Displays page now shows which screen each display is currently showing.

## Fixed

- Calendar feeds that use non-standard time zone names (like MDT or CST) now load instead of failing, and events stay correct across daylight-saving changes.
- Calendar grids no longer lose events on busy months, and views set to show past events now actually fetch those earlier days.
- The history module no longer comes up empty. The source was rate-limiting the app and the display could sit blank until the next day; it now retries properly and keeps the last known events on screen if a fetch fails.
- Full-screen weather no longer overlaps its own columns at large text sizes, and the hour labels on the temperature ribbon stay clear of the curve.
- Modules can no longer be dragged or resized off the edge of the canvas out of reach, and a module stays selected after you finish resizing it.
- The multi-month calendar now uses a steady six-week grid that fits its box, so months stop overflowing or shifting when the display loads.
- The login, remote, and chores pages no longer flash raw text labels while loading.
- Photo slideshows no longer briefly flash the photo from two slides back when advancing.
- News fixes: two publishers sharing an ID no longer hide each other's stories, word filters match whole words (so "war" no longer hides "Warsaw"), the paged list stops resetting while you read it, and feeds now supply their largest available image.
- Disconnecting OneDrive now clears its cached photos right away instead of continuing to serve them.
