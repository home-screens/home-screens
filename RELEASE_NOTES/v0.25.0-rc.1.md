## New

- Multi-week meal planning — plan meals across multiple future weeks with week-by-week navigation and a "Today" button in both the editor and remote control. "Copy Last Week" copies your full plan forward. Existing single-week plans are automatically migrated.

## Improved

- Searchable emoji picker in the meal detail form — filter emojis by keyword to find the right one faster
- Meal tag picker on the remote control now includes all available tags, matching the editor
- Chore chart member chips scale properly at larger text sizes, preventing points and streaks from overflowing
- WiFi reliability on Raspberry Pi — automatic reconnection with escalating recovery steps keeps headless displays online on mesh and flaky networks
- Update controls in the editor System section now appear regardless of how Home Screens was installed

## Fixed

- Ingredient category dropdown in the meal editor was invisible against the dark background
- Meal planner modal now returns to the library tab after saving a new meal
- Meal data stored in two separate locations could cause the editor and display to fall out of sync — now unified on a single source
