## New in this RC

- Fixed the Raspberry Pi image never starting its kiosk screen on first boot.
- Fixed the chore chart Board view squeezing everyone into one row of truncated columns on a busy day.
- Fixed the remote's Photos tab showing an empty state for households using the windowed photo module instead of the full-screen one.
- Added a proper first-run experience: a setup watermark naming your hub's address, empty-screen templates, a phone launcher page, and an in-editor checklist while you're still setting up.
- Added a password recovery tool for when you forget your editor password, plus clearer lockout messages after too many tries.
- The editor now warns you before overwriting someone else's changes, and lets you preview a screen you're editing in a separate tab without disturbing the live display.
- Added screen search to the editor toolbar (Cmd/Ctrl+K) to jump straight to a screen by name or by the modules on it.
- Added an arrows-only layout option for the display control widget.
- Added a settings page that explains the family phone pages (chores and remote control) with scannable QR codes.
- Calendar links and weather API keys are now checked before you save them, so a typo is caught immediately instead of failing silently later.
- Rebuilt the full-screen chore chart and rewards screen so they resize to fit any household size and any screen shape, and made the display control widget resize to fit its box too.
- Renamed and reorganized settings pages in plain language, with clearer descriptions and consistent naming throughout.
- Polished the editor workspace: collapsible panels, module search, clearer indicators for hidden/disabled modules, and consistent dialogs.
- Redesigned the remote control's forms and icon pickers to be easier to use on a phone, with bigger tap targets.
- Module schedules and time-based visibility rules are now shown as a visual week instead of a text description, and can span multiple days.
- Chore, star chart, and meal planner modules now scale properly for both large families and small screen boxes.
- Display errors (weather, traffic, calendar) now show friendly "needs setup" or "not updating" messages instead of raw errors or status codes.
- Remote controls now show confirm-or-revert feedback and live display status instead of assuming a command worked.
- The kid chores page remembers the last kid selected and lets you press-and-hold to undo a finished chore.

## Improved

- Rebuilt the full-screen chore chart and rewards screen to fit any household size and screen shape; the display control widget now resizes to its box too.
- Chore, star chart, and meal planner modules scale properly for both large families and small screen boxes.
- Settings pages renamed and reorganized in plain, friendly language with clearer descriptions.
- Editor workspace polish: collapsible panels, module search and descriptions, clearer hidden/disabled indicators, and consistent dialogs across the app.
- Remote control forms and icon pickers redesigned for phone use, with bigger tap targets throughout.
- Module schedules and time-based visibility rules now display as a visual week and support multi-day spans.
- The multi-week calendar can now go as low as 2 weeks.
- Short screen durations now show a warning instead of being silently increased.
- Wall display polish: better placeholders for unconfigured modules, clock views that scale instead of clipping, sports times shown in your local timezone, and clearer handling of missing background images.
- Display errors now show friendly "needs setup" or "not updating" messages instead of raw errors or status codes, across weather, traffic, and the rain map.
- Kid chores page remembers the last kid selected, adds a Yesterday/Today toggle, and lets you press-and-hold to undo a finished chore.
- Canvas drag-and-drop feedback, a guard against dropping a full-screen module onto a busy screen, and new editor keyboard shortcuts (arrows, delete, escape, duplicate).
- Remote status reporting shows a display's real last-seen time and confirm-or-revert feedback for every control.
- Calendar fetching now pages through all of your events instead of stopping at 250, so busy month and week views no longer show gaps; the old Max Events setting was removed since it's no longer needed.
- Weather ribbon hour labels no longer overlap the temperature curve at large text sizes.
- The display now renders using the app's own fonts everywhere, fixing fuzzy or wrong-weight text on the Raspberry Pi.
- Fullscreen weather content no longer overflows its column at large text sizes, and resized modules can no longer be dragged outside the canvas.
- Help docs rewritten around real household tasks, with better search that understands the way people actually phrase questions.
- Login and remote pages show translated text immediately instead of raw placeholder keys while they load; login lockout raised from 5 to 10 tries with properly translated messages.

## Fixed

- Raspberry Pi image never starting its kiosk screen on first boot.
- Chore chart Board view squeezing everyone into one row of truncated columns on a busy day.
- Remote's Photos tab showing an empty state for households using the windowed photo module.
- History module failing to load due to upstream rate limiting.
- Module staying deselected after finishing a resize drag in the editor.
- Star chart marking future days as missed in the evening.
- Fullscreen calendar week titles breaking when a week crosses a month or year boundary.
- News module dropping stories that share an ID across different feeds, and blocked-word filtering matching partial words (like hiding "Warsaw" because of "war").
- Cross-origin write requests to the API are now rejected for security.
