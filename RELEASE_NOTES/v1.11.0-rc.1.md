## New

- Event and day rules for both calendar modules: match events by title, calendar, location, all-day, finished, or type and then hide them or change their color, fade, icon, or displayed title; match days by today, past, future, weekday, or whether they have events and then set a background, fade, outline, or badge. Rules run in order, so the list itself is the priority.
- Birthdays and holidays now look like birthdays and holidays. They get their own glyph instead of the usual color dot, read "Birthday, turns 12" or "Holiday" instead of the generic all-day label, and birthdays get bold name-first text with a warm tint in the month grid. Works with iCloud contact birthdays, Google's Birthdays calendar, and the public holiday source.
- Calendar source legend: an optional list of which calendars are feeding the current view, at the top or bottom of either calendar module, showing only the sources that actually have events on screen.
- Calendar source health: if one calendar stops responding, the display keeps showing its last-good events with a "saved" marker instead of going blank, rings the failing source in the legend, and names it in the header. A new Source status list on the Calendar settings page says in plain language what went wrong and when each source last worked.
- Countdowns and progress on calendar list rows: show a countdown pill before an event starts and a progress bar while it is running, with a separate opt-in for all-day countdowns.
- Keyword filters for both calendar modules: include or exclude events by matching words in the title, plus a "Hide events you declined" option for Google calendars.
- Multi-week calendar themes: the original banner look plus three modern grids (clean, minimal, and vivid) with corner day numbers, a today ring, weekend shading, stitched multi-day bars, and overflow chips.
- Now rule and past dimming in the calendar's daily view: fade events that have already ended and draw a thin line between finished and upcoming events, with a live ring around whatever is running right now.
- "Show Today's Finished Events" for both calendar agenda views: events that ended earlier today stay visible for the rest of the day instead of disappearing the moment they end.
- Schedule start anchor for calendar views: begin at today, the start of the week, or the weekend.
- Weather placement in calendar views: put the forecast in the header, on day headers, or next to individual events, instead of a single on/off switch.
- Multi-day timed events now read correctly across days, with a real start time on the first day, an end time on the last, and all-day rows in between.
- Calendars can now drive conditional visibility and text: seven new live values (next event title, start, time, minutes away, events today, busy now, and all-day today) are published to the shared state bus, so any module can show or hide itself based on what is on the calendar. They work even on displays with no calendar module.
- Optional title strip on module cards: give any module a centered caption with its own size control, set in the Style panel.
- Per-module timezone for the Clock and Date modules: pick any timezone per module with a new searchable picker, or leave it blank to follow the display setting. The same picker now powers the Location settings page.
- Sky color theme for the sunrise and sunset circle view: a gradient ring through sunrise, noon, golden hour, sunset, and darkness, with scattered stars through the astronomical-dark window. Both themes now handle midnight sun and polar night.
- The homepage at homescreens.dev now walks through 21 real dashboard screenshots with descriptions and module lists, replacing the old rotating frame.
- Discord community links on the README, the marketing site, and the docs.

## Improved

- Calendar module settings are now grouped into labelled sections in the same order for both calendar modules: view picker, What shows, the current view's own settings, Event rows, Look, Advanced looks, and Touch. Settings that belong to other views no longer sit interleaved with the ones you are editing.
- Dark mode now covers scrollbars, dropdowns, and form controls, which previously stayed light against the dark app.
- The editor canvas zooms on fixed stops from 20% to 400% instead of drifting by a multiplier, and Ctrl+wheel moves exactly one stop per notch. Zoomed-in canvases can now scroll all the way to their left edge.
- The multi-week calendar grid got a visual pass: every day number sits in a shaded header tinted with the accent color, today keeps the stronger fill, and the gaps between day cells are wider.
- Custom empty-day wording and week or month separators in the calendar agenda views.
- Updated bundled dependencies to clear security advisories.

## Fixed

- Calendar setups using only iCloud calendars did not fetch any events at all, and iCloud calendars were missing from the editor's source filter.
- The fullscreen calendar placed events using the computer's clock instead of the display's timezone, so events could land on the wrong day or at the wrong position in every one of its five views. Events crossing a daylight-saving change now keep their real duration.
- The sun glow on the sunrise and sunset circle view stayed lit all night; it now turns off between sunset and sunrise, and the marker dims to match.
- Opening the Calendar settings tab could crash the editor when no Google calendars were configured.
- The fullscreen calendar's Density setting showed a raw internal name instead of its label.
- Multi-week grid fixes: the month abbreviation and day number no longer run together, day numbers and today's badge pick a readable text color against light accent colors, and weekday labels stay lined up with their columns when week numbers are shown.
- Embedded web pages in the iframe module no longer change appearance based on the app's theme, and the meal planner's time inputs now follow the app theme instead of being locked to dark.
