## New

- WiFi status indicator appears at the lower right of the display when network connectivity is lost, and clears immediately on reconnection
- WiFi provisioning via a wifi.txt file on the boot partition for headless setup on pre-built images

## Improved

- Cursor now hides properly on touchscreen displays using a new compositor
- Navigating to the root URL opens the editor instead of the display, matching the setup context for new users
- Restructured Raspberry Pi documentation with a dedicated pre-built image install guide

## Fixed

- Boot splash showing placeholder boxes instead of the dot animation
- Login prompt appearing unexpectedly on first boot of fresh images
- Kiosk files having incorrect ownership after image build
- Pre-built images shipping with the builder's WiFi credentials instead of a clean network state
