## New

- Four new weather providers — Yr.no, SMHI, UK Met Office, and Environment Canada — for better forecast accuracy outside the US
- Screen-level scheduling — show or hide entire screens by day of week and time window, on top of the existing per-module scheduling. A clock icon marks scheduled screens in the editor.
- Advanced mode toggle in System settings hides developer-only surfaces (release channel, GitHub token, plugin Developer tab) until you opt in
- New local-network plugin permission lets opt-in plugins talk to LAN devices like home automation hubs, while still blocking loopback and cloud metadata addresses

## Improved

- /remote now shows the profile pool that actually applies to the selected display, instead of always showing the global list
- Todoist module — tap a task to mark it complete, and tasks render as plain text instead of raw markdown like `[Watch](url)`
- Chore ticket balance updates instantly when you check or uncheck a chore
- Plugin install, backup restore, and plugin fetch paths hardened against malicious bundles, redirect-based SSRF, and plugin-ID collisions
- Documentation now links to the latest prebuilt Pi image automatically, with improved dark-mode contrast in callouts

## Fixed

- Expired /remote sessions now redirect to the login page instead of silently leaving you on a blank or broken screen
- Plugin upgrades no longer wipe out the API tokens and other secrets you've configured for the plugin
- The editor's Preview button opens the display you've selected in the multi-display switcher, instead of always opening the main display
