## New

- Conditional module visibility: show or hide any module based on live state published by other modules or plugins, using Home Assistant-style conditions (state match, numeric comparisons, and/or/not combinations) with a configurable fallback while the state is still unknown. The editor suggests available state keys and warns when a condition references a key that nothing on the display publishes.
- Background providers: mark a module as a background provider so its data keeps updating (and the state it publishes stays fresh) even while other screens are showing
- Plugins can publish state for other modules to react to, so plugin data such as a Home Assistant sensor can drive the visibility of any built-in module
- Tap-to-check todo lists: an optional interactive mode lets you check items off directly on a touch display, with changes syncing to every display within seconds

## Improved

- Word of the Day now draws from a curated 732-word list in each of the seven supported languages, rotating through every word before repeating (a full two years of daily words); each language gets authentic vocabulary of its own rather than translations of the English list
- Fullscreen calendar: choose how strongly today is highlighted (full, subtle, minimal, or off, tinted to match your accent color), pick side-by-side or stacked layouts for overlapping events, and optionally wrap long event titles onto a second line
- Per-module disable toggle: turn off a single module without deleting it; disabled modules stay visible and editable in the editor but skip rendering and data fetches on the display
- Local-network plugins such as Home Assistant integrations can now make 240 proxy requests per minute instead of 60, allowing near-realtime polling
- The Google Calendar setup code can be copied with one click, including on kiosk displays served over plain HTTP

## Fixed

- Fixed-date holidays showing on their observed date instead of their actual date, such as Independence Day 2026 appearing on July 3; this also fixes New Year's Day vanishing from January views in years when it is observed on December 31
- Meal plans, API keys, and chore history are no longer at risk of being silently wiped if their data file becomes corrupted; the system now reports the problem instead of resetting to defaults
