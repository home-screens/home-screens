## New

- Chore rewards system — kids earn points by completing chores and spend them on parent-defined rewards
- Wikipedia as a second data source for the history module, with richer event descriptions and per-source toggles in the editor
- Backup and restore from the remote control page — download a full data backup or restore from a previous export, right from your phone
- Configurable backup reminder that nudges you in the editor (and on the remote control page) when it's been a while since your last backup

## Improved

- Pause screen rotation on a touchscreen by double-tapping the active pagination dot

## Fixed

- Unfilled stars in the chore chart invisible on light themes, and light theme variants (Linen, Paper, Mist) now look visually distinct
