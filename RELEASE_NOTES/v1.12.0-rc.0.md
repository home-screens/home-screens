## New

- OneDrive as a photo source for the slideshow and fullscreen photo modules. Sign in with a Microsoft account using a short code, browse and pick a folder, and the slideshow pulls photos from that folder and everything inside it. Setup lives in Settings under API keys, with a full walkthrough in the docs.
- Stock ticker charts: each tile can show today's movement, the past week, or both side by side, with a new classic or shaded look and optional labels naming each chart's range.
- Single-symbol stock tiles, a view that dedicates the whole tile to one symbol with a large price, its change, and a full-tile chart.
- Show Title toggle on modules that draw their own heading (traffic, garbage day, history, news, todo, Todoist, weather, chore chart, and both meal planners), so you can drop the built-in title without losing the module's own counters.
- Import a layout straight from the + menu on the screen tabs, matching the existing Export This Screen action.
- Full release notes now open in a readable dialog from System settings, formatted properly and linked to the release page on GitHub, instead of being cut off after a couple of lines.

## Improved

- Rain radar is much lighter on the network. Tiles are cached and shared between screens and between multiple rain maps, the first frame appears immediately, and the animation only plays over frames whose tiles have finished loading, so a cold start no longer cycles through blank frames.
- Calendar month grids no longer get trimmed. The Max Events setting is gone; month views show the whole month instead of being cut back to the nearest few days on a busy calendar.
- The editor now shows per-source calendar health, so a feed that has stopped updating is flagged in the preview the same way it is on the display.
- Photo slideshows finish a full pass before picking up a refreshed photo list, so a background refresh no longer swaps the current photo mid-rotation or repeats photos early. Turning shuffle off now restores the original order without restarting the pass.
- Backgrounds and images hold the current picture on screen while the next one loads, instead of blinking to empty.
- Modules can no longer be dragged or resized off the edge of the canvas, so a resize handle is always reachable.

## Fixed

- Fonts in the picker now match on the display. Georgia in particular fell back to an unrelated font on the Raspberry Pi; a metric-identical face now ships with the app.
- A module no longer loses its selection the moment you finish resizing it.
- Fullscreen weather no longer overlaps its own content at larger text sizes: columns, the panorama hero, and the ambient hero all stay clear of the ribbon and alert band.
- Calendar feeds that use non-standard time zone names (like MDT or CST) now load instead of failing outright, and a single unresolvable time zone no longer throws away the whole calendar.
- The multi-month calendar keeps a consistent six-week grid and scales to fit its box, so six months side by side no longer run their columns through each other or flicker on load.
- The rain map no longer breaks the display page when it is the first thing to render, and a dropped connection no longer freezes tile loading for the rest of the session.
- Searching settings for OneDrive now finds its card.
