## Improved

- Redesign the settings page into two clear sections — Defaults for shared values and Per Display for display-specific overrides — so every setting has one obvious home
- Per-display settings fields now show explicit "Override" and "Reset to default" actions instead of silently inheriting, making it clear where each value comes from
- Defaults pages show a banner listing which displays currently override their fields, so you can spot divergence at a glance
- Each display now owns its own profiles, so profile screen references always match the display's actual screens instead of silently pointing at the wrong set
- Resetting a per-display override now fully removes it instead of leaving a stale value behind
