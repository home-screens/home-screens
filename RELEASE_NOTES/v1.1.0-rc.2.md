## New

- Rewards store view for the fullscreen chore chart — kids can browse available rewards, check their ticket balance, and redeem directly from the display
- Blog, changelog, and comparison pages on homescreens.dev for project news, version history, and a side-by-side feature comparison with MagicMirror and Dakboard

## Improved

- "Points" renamed to "tickets" everywhere — editor, remote control, kid view, and display all use consistent language
- Reward eligibility filtering — rewards can be restricted to specific members and the store hides anything a kid isn't eligible for
- Link to homescreens.dev added to the settings sidebar alongside the existing GitHub link

## Fixed

- Kids on the /chores view could not toggle chores or redeem rewards when a remote-control password was set
- Service restarts on Raspberry Pi no longer hang for up to 90 seconds when stopping the previous process
