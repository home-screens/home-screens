## New

- Remote diagnostics bundle — download a redacted ZIP from the Stats page containing your config, per-display status, browser console logs, plugins list, telemetry, and system journal. Makes it much easier to share useful context when reporting issues
- Per-Pi hardware reporting — each display Pi now posts CPU usage, temperature, memory, disk, uptime, and hardware details to the hub every 30 seconds. The Stats page gains a Display Hardware section and a CPU & Thermal panel so you can see at a glance if a Pi is running hot or low on space
- Reporter token management — rotate the shared token that display-only Pis use to post hardware stats, directly from the Stats page

## Improved

- Display-only Pi installer prompts for the reporter token during setup, and `upgrade.sh` refreshes the reporter script and systemd units on every upgrade so existing Pis pick up fixes automatically
- Fresh browser console logs can be pulled on demand when a diagnostics bundle is generated, instead of relying on whatever happened to be buffered

## Fixed

- Stale or stub status posts from the hardware reporter can no longer overwrite a display's real rotation status on the hub
