## New

- iCloud calendar sync — connect one or more iCloud accounts with app-specific passwords in Settings > Calendar, pick which calendars to show (Apple calendar colors preserved), and optionally include birthdays from your contacts
- Video support — new Video module that plays library files, direct URLs, and YouTube links; photo slideshows and the fullscreen photo viewer can mix videos into rotation, and the image library is now a full media library with video thumbnails and uploads up to 200 MB
- iCloud photos and videos — use iCloud Shared Albums (including the newer photos.icloud.com/shared links) as a slideshow or background source, or import from an iCloud link straight into your media library
- Tap a meal to open its recipe — meal planner modules can show a QR code or the recipe page itself in a fullscreen overlay; screen rotation pauses while it's open
- Plugin account connections — plugins can now sign in to services that require an account (OAuth-based APIs and Garmin Connect) through a new Connection panel in the editor; sign-ins are stored securely and survive upgrades
- Live values for visibility conditions — the editor now shows each shared-state key's current value next to condition inputs and warns about case mismatches, and Text modules can embed live state values with {key} tokens
- New Health & Fitness module category, ready for fitness plugins like Strava and Garmin

## Improved

- Redesigned upgrade window with step-by-step progress, per-step timing, and a live console you can follow while an upgrade or rollback runs
- Month and week calendar grids now show the whole grid, with past days dimmed, instead of starting at today — and later weeks no longer run out of events
- Sleep and dim schedules, moon phase, and sunrise/sunset now follow the display's configured timezone instead of the device's system timezone
- Modules shown or hidden by shared-state conditions no longer blink when their data source restarts or a plugin reloads
- Stronger access control: the hub no longer trusts forged network headers for IP allowlists and login rate limits, and error messages no longer reveal server file paths
- Rain map radar tiles that fail to load are retried instead of staying blank, and the map uses less memory over long sessions
- Weather modules stop polling when no location is configured instead of failing over and over in the background
- Anonymous telemetry now includes which marketplace plugins are installed (side-loaded plugins are never identified); the what-we-collect page is updated in all languages

## Fixed

- Saving an invalid Todoist token kicked the editor back to the login page instead of showing the error
- Server crash when a display skipped or stopped a video mid-download
- Plugin translations always showed English instead of the configured language
- Plugin modules set as background providers never started their data loop
- Editor froze when selecting a Display Control module before any displays were registered
- The rewards screen could open with no family member selected
- Layout export and import now use the selected display's profiles in multi-display setups
- An editor save made while the hub was starting up could be overwritten by the startup migration
- Fullscreen meal planner and photo clock overlays used browser time instead of the display's timezone
- Background uploads that were too large now get a friendly "file too big" message instead of a server error, and video uploads over 10 MB are no longer silently cut off
- Photo grid overflowed its frame in the image browser
