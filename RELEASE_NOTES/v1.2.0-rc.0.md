## New

- Network settings page — manage Wi-Fi, saved networks, static IP, and hostname directly from the editor. Includes connectivity diagnostics (ping + watchdog) and auto-rollback if a network change cuts off the device. Supports source-based routing for dual Wi-Fi setups, including USB adapters
- Touch-enabled display-control module — drop it on any screen to give family members a tap-friendly surface for switching screens, changing brightness, or putting a display to sleep. Three layouts (bar, pad, panel), 1-second hold-to-confirm on sleep, and runtime target picker for All, Self, or a specific display
- One-time chores — a new "once" frequency lets you schedule a chore for a specific calendar date instead of a recurring weekly pattern. Date picker available in both the editor modal and the remote control manage view
- Per-screen rotation duration — override the default rotation interval on individual screens. A duration pill appears on screen tabs when you've set a custom value, and fullscreen-photo prefetch timing respects the per-screen value
- Single-photo mode for the fullscreen photo module — pick a single image to display instead of rotating through an album. Slideshow-only controls (interval, transition, shuffle) are hidden when a single photo is selected
- Install plugins from a URL — paste a manifest URL in plugin settings to install without copying files manually

## Improved

- Property panel polish — config fields share a grouped layout, the background picker lives in its own accordion section, and a divider separates screen settings from background. The background picker now hides when a module is selected so the panel stays focused
- Screen rotation settings appear in the empty property panel so you can adjust rotation without selecting a module first
- Rotating modules no longer cross-fade between rotations, eliminating flicker on the Pi display
- `curl | bash` one-line install — bootstrap Home Screens on a fresh Pi without cloning the repo first. OS optimizations (zram swap, tmpfs, fd limits, WiFi autoconnect dispatcher, boot tuning) now run during upgrades too, not just fresh installs
- Image-creation script adds SHA-256 checksum verification for downloaded tarballs
- Plugin install errors surface useful messages instead of generic failures
- Blog documents the new install method and adds an RPI Imager navigation hint for the OS Lite image

## Fixed

- Duplicate Chromium windows on the Pi kiosk that caused a display command race
- Rain map tiles failing to load, centering incorrectly, and hitting provider rate limits
- Iframe module not loading or rendering embedded content correctly
- Wi-Fi scan, password visibility, and nmcli compatibility issues on some Pi setups
- Install script crashing with "unbound variable" during bootstrap cleanup
