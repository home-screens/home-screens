## New

- Conditional module visibility: modules can now show or hide automatically based on live values published by other modules or plugins (for example, hide a panel while a Home Assistant plugin reports the TV is on). A visual condition builder in the editor suggests available keys and warns when a condition references a key nothing is publishing.
- Background providers: mark a module as a background provider to keep its data running across screen rotations, so the values it publishes stay fresh even while it is off screen.
- Interactive to-do lists: turn on tap-to-check to mark items done right on the touchscreen. Checked state syncs across all your displays within a few seconds.

## Improved

- Per-module show/hide toggle: temporarily disable any module without deleting it. Disabled modules stay visible (dimmed) in the editor but are skipped on the display.
- Fullscreen calendar options: choose a today-highlight style (full, subtle, minimal, or off), pick how overlapping events are laid out (side-by-side columns or a cascading stack), and optionally wrap long event titles onto two lines.
- Local network plugins (such as Home Assistant integrations) can now make four times as many API calls per minute, enabling near-realtime polling of devices on your LAN.
- The Google Calendar sign-in code can now be copied with a single tap.

## Fixed

- Fixed-date holidays (New Year's Day, Juneteenth, Independence Day, Veterans Day, Christmas) now appear on their true calendar date instead of the shifted "observed" date when they fall on a weekend. New Year's Day no longer vanishes from January when it is observed in late December.
- Corrupted data files (meal plans, API keys, chore history) now surface a clear error instead of being silently reset to defaults, protecting your saved data.
