## New in this RC

- New multi-week calendar view: see the current week plus the next several weeks (4 to 12, your choice) in one grid, with month labels, a highlight on today, and a cap on how many events show per day
- Choose whether calendar grids start the week on Sunday or Monday; Monday-start weeks use standard ISO week numbers
- New "stay awake" setting for sleep and dim schedules: waking or touching a display during a scheduled sleep window keeps it awake for a set time (5 minutes by default), and changing screens from the remote now wakes a sleeping display
- The "needs setup" prompt for display software now stands out, includes a ready-to-copy SSH command built from the display's own address, and no longer truncates the commands it asks you to run
- Fonts now ship with the app instead of being downloaded from Google at build time, so builds work offline and can't fail because of a font server outage
- Fix calendar grid issues: today is highlighted using the display's timezone, week numbers match their rows across year boundaries, and a hand-edited weeks value that isn't a number falls back to the default instead of showing an empty grid

## New

- Multi-week calendar view: the fullscreen calendar can show the current week plus the next 4 to 12 weeks in one grid, with month labels, a highlight on today, and a per-day event cap
- Automatic software updates for display-only Pis: displays fetch updates from the hub nightly and at each start, verify them before applying, and keep the previous version so a bad update can roll back. The hub avoids advising a restart while a display is in use, a new Display software card in the editor shows each display's update status, and older installs get a one-time command to switch on self-updates
- Module layering controls in the editor: Bring to Front and Send to Back buttons, and clicking the same spot repeatedly cycles through overlapping modules so covered ones stay reachable
- Per-module font weight in the Style panel: pick any weight from thin to black for a module's text, with a reset back to the default
- Weather modules can show a location header above the forecast: a custom label, the place name, or the coordinates
- Plugin store upgrades: each plugin links to its project page, and a new release notes view lists every version with its changelog, release date, and a warning when a version isn't compatible with your install

## Improved

- Calendar grids (week, month, and multi-week) can start the week on Sunday or Monday, with ISO week numbering for Monday starts
- Sleep and dim schedules gained a "stay awake" hold: activity during a scheduled window keeps the display awake for a set time instead of it going right back to sleep, and remote navigation wakes a sleeping display
- Idle dimming is now its own toggle, separate from the sleep and dim schedules, so a display can sleep on a schedule while staying at full brightness the rest of the day; the sleep settings are regrouped into clearer sections with a 24-hour preview of the resulting day
- Complete Danish translation (over 2,500 strings that were still in English), plus stray untranslated strings fixed in German, Spanish, French, Dutch, and Portuguese
- The display software "needs setup" prompt stands out more, offers an SSH command built from the display's own address, and shows commands in full so they can be read before being run
- Fonts are bundled with the app instead of fetched from Google at build time, making builds smaller, offline-friendly, and immune to font server outages
- The README quick start now leads with the pre-built image, documents the one-line curl install and installer options, and corrects the architecture diagram and backup instructions

## Fixed

- Calendar grids highlighted the wrong "today" when the display's timezone differed from the device clock; week numbers could mismatch their rows across year boundaries; a hand-edited weeks value that wasn't a number showed an empty grid; accent tints now work with non-hex accent colors
- Countdown modules rendered larger in the Next view than the All view at the same size setting; a given size now looks the same in every view, and existing setups are adjusted automatically so nothing changes on screen
- Weather views no longer overflow their box: the current, daily, and combined views could spill past their edges at many sizes, and the compact view could squash its icon and wrap its temperatures in tall boxes; all four now measure their content and scale to fit
