## New

- Display Rules: set up automations that react to shared state or the time of day, like taking over a screen for an alert, waking a sleeping display, or putting one to sleep. Rules include a visual condition builder, live "met/not met" status on each card, can be copied to another display, and a takeover only fires on a real change so a restart or reboot won't trigger it by accident
- Plugins can publish live values on demand: referencing a value in a visibility condition or Text token is enough to make it start publishing, with no module needed on screen. Plugins can also offer their own settings, edited right from the plugin manager and applied to running displays without a reload
- Shared state now has a searchable "Available" tab that browses every value your plugins can provide (grouped by add-on), not just the ones you've already used in a condition or text token
- Plugin beta channel: opt in to beta versions of plugins from the plugin store, with a toggle in Browse, beta badges throughout, a separate upgrade offer that doesn't require switching your whole install to beta, and a one-step way back to the stable version that keeps your settings and connected accounts

## Improved

- Settings has been reorganized into grouped, tabbed pages (Screen, Content, Automation, Maintenance), the sidebar search now matches individual fields and jumps straight to the setting with a brief highlight, and several pages were renamed to say what they hold, like "System & updates" and "Backups & data"
- Clock's Elapsed view and the Countdown module can now choose a display format (flip cards, timer style, or spelled-out words) and how much precision to show, with a live preview in the editor
- Visibility conditions gained "or equal to" checkboxes for numeric comparisons, a friendly search for state keys (readable labels, current values, and known options) when building a condition, and Text module tokens can now format values inline, like rounding a number or supplying a default
- The editor now shows live status for every visibility condition and rule, using real data reported by your displays, plus a Live values page that shows what's published versus what's actually being used and warns when a plugin's data source stops reporting
- A misbehaving add-on now fails in place instead of taking everything with it: a plugin that crashes shows an error in its own spot on the screen, leaving the rest of the kiosk running and your unsaved editor changes intact
- Plugins now declare which app version they require; the plugin store automatically picks the newest compatible version instead of just the first one listed, blocks incompatible installs and updates, and names the exact version you have installed when it differs from the release being shown
- A plugin dev override now falls back to your installed copy if the dev server becomes unreachable, and picks the dev copy back up automatically once the server returns
- Background editor tabs pause their plugin data connections after being hidden for a minute, and screen prefetching correctly pauses during rule takeovers
- Very long Todoist lists now show their count as "4000+" rather than quietly reporting a smaller number as exact, and the Danish task counts are translated
- Documentation has been refreshed to match the reorganized settings pages and the new Clock and Countdown options

## Fixed

- Plugins with a minimum app version requirement were incorrectly hidden or blocked on release-candidate builds of the exact version they require
- Todoist task lists longer than one page were being silently cut off; task fetching now pages through all results and tolerates temporary Todoist errors without losing projects, sections, or labels
- A rule takeover could keep a display lit all night if its condition stayed true; sleep now resumes 5 minutes into a takeover while the takeover keeps its screen pinned
- A display put to sleep by a rule, the remote, or a touch control could not always be woken by touching the screen, and turning sleep off could leave a screen stuck asleep
- Clock's Elapsed view in timer format no longer looks like it resets when it crosses an hour or a day; the rightmost number is always seconds
- Bookmarks to the old Sleep, Rules, and Profiles settings pages now open on the tab they became, settings search no longer lists fields that aren't actually on the page, opening a display's settings shows that display's rules rather than another one's, and switching tabs right after an edit no longer drops it
- The editor briefly showed condition-based modules as hidden while a plugin restarted; it now matches what the display is really doing and marks a value that has stopped updating
- Plugin settings could read as empty for fields the settings form showed as filled in
