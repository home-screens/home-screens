## New

- Full-Screen Calendar can show event descriptions on the Family grid and Up next views, with a Show Description toggle for each (off by default). Family grid gives each event only the lines its description needs, and Up next trims descriptions first when the board would run past its box.
- A background wall for every full-screen theme, painted from the theme's own colours, so a regular screen matches a full-screen screen sitting next to it. Ten new gradients (Ocean, Ember, Ink, Moss, Copper, Lavender, Cloud, Sand, Sage, Blush) and four patterns (Dots, Grid, Diagonal, Paper) join the shipped set. The picker groups walls into theme, colour, and pattern sections, lists your display's theme first and marks the one in use, and shows tiles in your display's orientation. Every wall paints correctly on both portrait and landscape displays.

## Improved

- Setting up WiFi from a wifi.txt file on the SD card now retries on every boot until it works, so a mistyped password can be corrected without reflashing. Passwords are saved exactly as typed, including spaces, quotes, and backslashes, and are checked for a valid length before saving. The country defaults to US when not set.
- When Home Screens needs the device password to update, change the hostname, connect or forget WiFi, or restart, the editor asks for it in place and retries the action. The Pi image grants this up front, and installs from older versions can be repaired from the editor or over SSH.
- Release images are held for hardware testing before they are attached to a release, so every published image has been booted on a real Pi.

## Fixed

- The built-in backgrounds now live in their own folder instead of alongside your uploads, so an update no longer leaves stale copies of them in your backgrounds folder. Screens that use a built-in wall are pointed at the new location automatically.
- Adding WiFi from the editor on a Pi that was started over Ethernet failed silently because the image shipped with the WiFi radio off. It now ships on.
- A wifi.txt whose last line had no line break dropped the password and joined the network as open.
- Chromium no longer offers to translate displays running in a language other than English.
- An interrupted update could leave the display unable to start; the service now recovers the previous version on boot.
