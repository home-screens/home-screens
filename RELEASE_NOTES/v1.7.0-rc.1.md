## Improved

- Redesigned the software update window with a step-by-step progress rail, version badges, and a live console so you can watch each update step as it runs
- Anonymous usage stats now include which marketplace plugins are installed, so we know which plugins to prioritize. Only marketplace plugin names are sent; plugins you side-load yourself are never identified. You can review or opt out anytime in Settings
- Device installs and updates now check for the correct npm version and fix it automatically, preventing update failures on devices set up with an older version
