## New

- Rebuilt the news module to support multiple feeds and a new full-screen news view, with smarter image selection.
- Added Microsoft OneDrive as a photo source — sign in, browse your folders and subfolders, and include those photos in your slideshow.
- Added opt-in credential backup.
- Added a "Show Title" toggle for modules with a built-in header.
- Added single-symbol mode to stock ticker tiles.
- Added day and week chart ranges to stock ticker tiles, with optional date labels.
- Added layout import to the screen tabs menu.
- Added a changelog dialog so you can view full release notes from inside the app.

## Improved

- Weather ribbon hour labels no longer overlap the temperature curve.
- Display now renders in the app's own font instead of falling back to a generic system font.
- Multi-month calendar now uses a fixed six-week grid so it always fits its space.
- Fullscreen weather no longer overflows its column, and resized modules stay inside the canvas.
- Calendar grids no longer trim events to a per-user cap.
- Rain map tiles are cached and back off automatically when rate-limited, for more reliable loading.
- Slideshow keeps showing the previous image while the next one loads and rebuilds slide order correctly when shuffling.
- Font picker's Georgia option now matches what actually renders on the display.
- Blocked cross-site requests from writing to your configuration, closing a security gap.

## Fixed

- Login and remote control pages no longer briefly show untranslated text while loading.
- News module header controls no longer show on views that don't have a header.
- Selected module stays selected after finishing a resize drag in the editor.
- Calendar feeds with non-standard time zone IDs now display correctly.
- Auth-protected images no longer serve a stale cached copy.
