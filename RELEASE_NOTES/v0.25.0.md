## New

- Immich photo library integration — browse and display photos from a self-hosted Immich server in slideshows, the fullscreen photo viewer, background rotation, and the background picker
- Wikipedia as a second source for the history module — events from Wikipedia and MuffinLabs are combined and deduplicated, with independent source toggles in the editor
- Chore rewards system — kids earn points by completing chores and redeem them for parent-defined rewards
- Backup reminder — a configurable toast notification in the editor when you haven't backed up recently
- Backup and restore on the remote control page — download and restore full data backups directly from your phone
- Touchscreen pause — double-tap the active pagination dot to pause screen rotation
- Offline indicator — a WiFi icon appears on the display when network connectivity is lost
- WiFi provisioning via boot partition — configure WiFi by placing a wifi.txt file on the SD card before first boot

## Improved

- Redesigned Integrations settings page with card-based layout, service icons, connection status badges, and category groupings
- Multi-week meal planning with calendar-based dates, week navigation, and a Today button for planning ahead
- Emoji picker in the meal form now includes search filtering and a larger grid
- Fullscreen chore chart member chips size dynamically to prevent overflow at larger text sizes
- Root URL now redirects to the editor instead of the display for easier initial setup
- Replaced Cage with labwc compositor for proper cursor hiding on touchscreen displays
- WiFi reliability hardening for Raspberry Pi — driver stability patches, infinite reconnect retries, connectivity watchdog, and kernel memory reservation

## Fixed

- Invisible unfilled stars in chore chart light mode; Linen, Paper, and Mist light themes are now visually distinct
- Plymouth boot splash showing squares instead of dots
- First-boot login prompt on fresh images
- Kiosk file permissions preventing normal operation after image build
- Pre-built images could ship with the builder's WiFi credentials
- Ingredient category dropdown in meal planner invisible against the dark background
- Update controls in the editor now appear regardless of install method
