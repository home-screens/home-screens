## New

- Shape & Divider module with 15 views — lines (divider, double-line, wave, zigzag, dotted), geometric shapes (rectangle, circle, triangle, polygon, star, arrow), and atmospheric effects (glow, gradient, grid, frame) for adding structure and polish to your screens
- Icon module with a visual Font Awesome 7 picker — drop any icon onto a screen, self-hosted so no CDN dependency

## Improved

- Text module typography overhaul — 10 built-in fonts with a visual picker, plus weight, italic, line-height, word-spacing, and decoration controls; new outline, drop-shadow, 3D, neon, wave, bounce, shake, and color-cycle effects; per-character animation and reveal-on-rotation
- Countdown module gains a "stay on the day" option — events stay visible (and yearly events stop rolling forward) until the end of the event day, rendering a "Today!" badge instead of disappearing at midnight
- Updated core dependencies and resolved a uuid security advisory

## Fixed

- Editor drag-and-drop now lands modules at the correct position when the palette or canvas is scrolled
