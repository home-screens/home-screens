## New

- Network settings page — scan and connect to WiFi, edit hostname, switch between DHCP and static IP, and run ping/watchdog diagnostics, all from the editor
- Touch-enabled Display Control module — on-screen buttons to wake, sleep, change brightness, and navigate between screens, targeting either the current Pi, a specific display, or all displays
- Per-Pi hardware reporting with a redesigned Stats section — each display reports CPU, memory, disk, and temperature, shown as ring dials with clearer section icons
- Install plugins directly from a URL, alongside the existing upload flow
- One-time chores — pick a specific date for a chore from the /remote manage view or the editor modal
- Per-screen rotation duration — override the global rotation time on individual screens, with a pill on the screen tab showing custom values
- Single-photo mode for the fullscreen photo module

## Improved

- Simpler hardware telemetry setup — the reporter token prompt is gone; the hub now trusts adopted displays reporting from the LAN
- Install flow parity between USB image creation and `curl | bash`, including a navigation hint for selecting the Raspberry Pi OS Lite image in RPI Imager
- Property panel polish — grouped controls, cleaner Screen-settings / Background separation, Background picker tucked into an accordion and hidden while a module is selected
- Plugin install errors now surface clearer messages when something goes wrong
- Hardened hostname updates, source routing, and rollback lifecycle so a bad network change can't strand a Pi
- Smoother rotating modules — removed enter/exit transitions that caused visible flicker during screen changes

## Fixed

- Rain map tiles failing to load, recentering incorrectly, and hitting tile-server rate limits
- Iframe modules failing to load or render correctly on the display
- Duplicate Chromium windows on the Pi causing display commands to race and misfire
- Display Control module bugs surfaced during live testing
- WiFi scan results, password-visibility toggle, and nmcli compatibility on newer Pi OS builds
- Installer crash from an unbound variable in the bootstrap cleanup trap
