## New

- Automatic software updates for display-only Raspberry Pis: each display checks nightly and on every start, verifies what it downloads from the hub, and keeps a rollback copy in case an update goes wrong. A display that's asleep can be restarted right away, while one in use waits. Displays set up before this release get a one-time command to switch on self-updating, and the editor shows each display's software version and update status
- Weather modules can show a location name above the forecast; use your own label or let it fall back to the place name for your coordinates
- Layer overlapping modules in the editor: Bring to Front and Send to Back buttons control which module sits on top, and clicking the same spot again cycles through overlapping modules so covered ones stay easy to select
- Choose a font weight for any module in the Style panel, from thin to extra bold, with a reset back to the module's own default
- The plugin store now links each plugin to its project page and adds a release notes view listing every version with its changelog, release date, and whether it works with your install

## Improved

- Idle dimming is now its own switch, separate from the sleep and dim schedules, so a display can sleep at night while staying at full brightness all day. The sleep settings are regrouped into inactivity, daily schedules, and dimmed appearance, with a 24-hour preview bar showing how your day will look, and a display returns to full brightness right away when dimming is switched off
- Danish is now fully translated (around 2,500 strings previously showed in English), and the Danish clock uses natural time phrases like "halv elleve". A handful of leftover English strings in German, Spanish, French, Dutch, and Portuguese are translated too
- A countdown's size slider now means the same size in every view; countdowns using the Next view keep the size they had, automatically
- The README now leads with the ready-to-flash image, documents the one-line install command and installer options, and corrects the architecture diagram, backup instructions, and the path for adopting a new display

## Fixed

- Four weather views (current, daily, compact, and combined) could overflow their box, wrap forecast days onto extra rows, or squash their content at certain sizes. They now measure their content and pick the largest size that fits, at any module size and combination of settings
