## New

- Multi-week calendar view: see the current week plus up to 12 more in one grid, with month labels on month-start days, dimmed past days, and today highlighted
- Colored calendar events: grid views can now show all-day events as solid pills in their calendar's color and timed events in colored text, with a classic style toggle per module
- Household time format: pick 12-hour or 24-hour once in settings and calendars, meal times, and event details all follow it
- 24-hour circle view for the sunrise & sunset module, plus an option to show when full darkness begins and ends each night
- Automatic software updates for display-only Raspberry Pis: displays check for updates nightly and at startup, apply them safely with rollback, and never restart a display that's being used
- Module layering controls in the editor: bring a module to the front or send it to the back, and click the same spot repeatedly to select modules hidden underneath
- Per-module font weight in the Style panel: set any module's text from thin to bold with a slider

## Improved

- Weather modules can show a location name header, using your own label or the place name looked up from coordinates
- Sleep and dimming settings got a new "stay on" hold: waking or touching a display during a sleep or dim window keeps it on for a configurable number of minutes, and remote navigation now wakes a sleeping display
- Idle dimming is now its own toggle, so a display can sleep on a schedule while staying at full brightness the rest of the day; the sleep settings page is reorganized with a 24-hour preview of the resulting brightness
- The fullscreen calendar can start the week on any day, matching the other calendar modules
- The plugin store now links each plugin to its project page and shows a release notes history for every version
- Completed the Danish translation and cleaned up leftover English text in the German, Spanish, French, Dutch, and Portuguese translations
- The setup prompt for a new display stands out more and offers ready-to-copy setup and SSH commands built from the display's own address
- Editor polish: module name chips and status badges now follow the module's rounded corners
- The app's fonts now ship with it instead of being downloaded from Google during builds

## Fixed

- Events that cross midnight now appear on every day they cover, with each day showing only its own portion, instead of only the starting day
- Calendar grid views: week numbers now match their rows for Monday-start weeks, today's highlight follows the display's timezone, and a bad week-count value falls back to the default instead of an empty grid
- Weather views no longer overflow or squash their content: the current, daily, compact, and combined views measure themselves and pick the largest size that fits
- Countdown scale now means the same size in every view, so the flip cards no longer jump in size when switching between the Next and All views
