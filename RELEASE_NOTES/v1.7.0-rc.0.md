## New

- iCloud calendar sync: connect one or more iCloud accounts in Settings > Calendar using app-specific passwords, pick which calendars to show, and optionally add birthdays from your iCloud contacts
- iCloud photos: use iCloud Shared Albums as a source for photo slideshows and background rotation, and import photos or videos from an iCloud link straight into your library
- Video module: play videos from your library, a direct URL, or YouTube. Photo slideshows and the fullscreen photo viewer can now mix videos into the rotation, and the image library is now a full media library with video thumbnails, uploads up to 200 MB, and Immich video support
- Tap a meal on the meal planner to open its recipe right on the display, as a scannable QR code or an embedded page (with a QR fallback for sites that block embedding)
- Live values for visibility conditions: the editor now shows what each display is actually publishing next to condition inputs, with warnings for mismatched key names. Text modules can also show shared state values using {key} tokens

## Improved

- Calendar month and week grids now show the whole grid, with past days dimmed, instead of starting at today; list and agenda views still show only upcoming events
- The built-in affirmations are now translated into all seven supported languages
- Stronger network security: access rules now use the real connection address, so spoofed request headers can no longer get around the IP allowlist
- Regional language variants (like Austrian German) now fall back to the closest matching language instead of English
- Chore completion history is now included in backups
- Modules that briefly lose a shared state value during a plugin or producer restart no longer blink; values are held for a short grace window

## Fixed

- Saving an invalid Todoist token no longer kicks the editor back to the login page; it now shows what went wrong
- Plugin text now follows your selected language instead of always showing English
- Display sleep and dim schedules, moon phase, and sunrise/sunset now follow the display's configured timezone instead of the Pi's system timezone, and fullscreen clock overlays do too
- Layout export and import now use the selected display's profiles in multi-display setups instead of the shared pool
- Rain map tiles that failed to load once stayed blank forever; they now retry, and the map no longer slowly uses more memory the longer it runs
- Weather modules no longer request data endlessly when no location is configured
- The rewards screen now starts with the first family member selected instead of appearing empty
- Uploads over 10 MB were silently cut short; large photo and video uploads now work, and files that are too big get a clear error message
- Fixed an editor freeze when selecting a display-control module on a single-display setup
- Plugins that only publish background data now start correctly instead of never mounting
- Fixed a rare startup race where a config upgrade could overwrite a save made in the editor at the same moment
