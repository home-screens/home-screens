Sun ring color playground

24h circle view · gradient between sunrise, sunrise +90m, noon, sunset −90m, golden hour, sunset, dark begin, dark end · stars in the dark window

Location & date

Sun times for that day of the year (the date is shown next to it), computed locally by the same math as the module (a port of suncalc), shown in the timezone above (any IANA name; unknown names fall back to this computer's zone). Changing these refills the event times below — try 69.65° around day 166 for midnight sun, or 53.55° for a night that never gets fully dark.

Colors

The +90m / −90m stops move with the sunrise and sunset time inputs; the golden-hour stop moves with the golden-hour time input and stays in the gradient even when its dot is hidden. When the night never gets fully dark, its halfway point takes the dark-begin color. The now marker's disc and daylight glow use the sun color.

Event times

Auto-filled from the location and month above; edit any single time to tweak it. A cleared time means the event does not happen that day.

Stars in the dark window

White single-pixel dots along the dark arc, each at its own brightness (25–80%). The scatter is seeded from a constant, so every load renders the same stars; Reshuffle cycles to the next seeded layout.
